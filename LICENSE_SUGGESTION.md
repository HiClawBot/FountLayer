# License Suggestion

Recommended split:

- SDK, protocol schema, examples: MIT or Apache-2.0.
- Basic Gateway, Faucet Engine, Ledger Engine: Apache-2.0.
- Managed cloud service, advanced anti-abuse, hosted key pool, settlement, enterprise features: commercial add-ons.

Before publishing, choose one actual LICENSE file for the open-source repository. Apache-2.0 is recommended if patent language matters; MIT is recommended if maximum simplicity matters.
