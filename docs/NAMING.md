# Naming

## Recommended Name

**FountLayer**

Chinese name: **智泉层**

Tagline:

> The open LLM last-mile distribution layer for apps.

## Why this name

- `Fount` means source or fountain, matching faucet credits and AI supply.
- `Layer` signals infrastructure rather than a single chatbot or app.
- It avoids sounding like an API resale shop.
- It is short, memorable, and productizable.

## Avoided Candidates

- MileFlow: good meaning but appears to be used by unrelated products.
- AIConduit: descriptive but already appears in use by unrelated AI/WordPress contexts.
- AIFount: too close to existing AI directory naming.
- TokenBridge / ModelFlow / LLMFlow: too generic and likely crowded.

## Naming Disclaimer

This is a rough product naming recommendation, not a legal trademark clearance. Conduct formal trademark and domain checks before commercial launch.
